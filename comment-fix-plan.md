# План исправления проблем с комментариями

## Проблемы:
1. **Кнопка отмены не работает** при написании ответа на комментарий
2. **Неправильное отображение ответов** после перезагрузки (сливаются)
3. **Лайки на ответах не отображаются** до перезагрузки

## План действий:

### Шаг 1: Найти компоненты комментариев
- Найти основной компонент комментариев
- Найти компонент формы ответа
- Найти компонент отображения комментариев

### Шаг 2: Исправить кнопку отмены
- Проверить обработчик onClick кнопки "Отмена"
- Убедиться, что состояние формы ответа правильно сбрасывается

### Шаг 3: Исправить отображение ответов после перезагрузки
- Проверить структуру данных комментариев (parent_id, nested replies)
- Проверить CSS стили для вложенных комментариев
- Убедиться, что отступы применяются корректно

### Шаг 4: Исправить отображение лайков на ответах
- Проверить, что данные о лайках передаются для ответов
- Проверить компонент отображения лайков для ответов
- Синхронизировать оптимистичное обновление UI

### Шаг 5: Тестирование
- Проверить кнопку отмены
- Проверить отображение после перезагрузки
- Проверить лайки на ответах
