# 🌓 Темная тема в PageGlow

## ✅ Что реализовано

Полноценная система переключения светлой/темной темы с:
- Мгновенным применением без мерцания
- Сохранением предпочтений в localStorage
- Поддержкой системных настроек
- Плавными анимациями перехода
- Доступностью (Aria-атрибуты, клавиатурное управление)

## 🎨 Как это работает

### Переключатель
Расположен в шапке сайта (справа, перед поиском):
- ☀️ **Солнце** - активна темная тема (нажмите для включения светлой)
- 🌙 **Луна** - активна светлая тема (нажмите для включения темной)

### Логика работы
1. **При первом посещении**: используется системная тема устройства
2. **После переключения**: тема сохраняется в localStorage
3. **При повторном посещении**: загружается сохраненная тема

### Файлы
```
PageGlow/

    └── base.html            # Подключение переключателя
```

### CSS переменные
Тема использует CSS переменные для легкой кастомизации:

**Светлая тема (по умолчанию):**
```css
:root {
  --bg: #f7f8fb;
  --surface: #ffffff;
  --text: #1f2937;
  --muted: #6b7280;
  --border: #e5e7eb;
  --bg2: #f1f5f9;
}
```

**Темная тема:**
```css
.dark-mode {
  --bg: #191a1b;
  --surface: #222325;
  --text: #ffffff;
  --muted: #8892b0;
  --border: #2a2f33;
  --bg2: #2a2b2d;
}
```

### JavaScript API
```javascript
// Переключить тему
PageGlowTheme.toggle();

// Установить темную
PageGlowTheme.setDark();

// Установить светлую
PageGlowTheme.setLight();

// Получить текущую тему
PageGlowTheme.getTheme(); // 'dark' или 'light'
```

### События
```javascript
// Слушать изменения темы
window.addEventListener('theme-change', (e) => {
    console.log('Тема изменена:', e.detail.isDark);
});
```

## 🎨 Кастомизация

### Изменение цветов темы
Отредактируйте переменные в `app.css`:

```css
:root {
  /* Светлая тема */
  --bg: #your-color;
  --surface: #your-color;
  /* ... */
}

.dark-mode {
  /* Темная тема */
  --dark-bg: #your-color;
  --dark-surface: #your-color;
  /* ... */
}
```

### Добавление анимаций
По умолчанию используется плавный переход 0.3s. Измените в CSS:

```css
body {
  transition: background-color 0.3s ease, color 0.3s ease;
}
```

### Отключение системной темы
Если хотите игнорировать системные настройки:

```javascript
// В theme-toggle.js, функция initTheme()
function initTheme() {
    const savedTheme = localStorage.getItem(THEME_KEY);
    if (savedTheme) {
        applyTheme(savedTheme === 'dark');
    } else {
        // Вместо системной - светлая по умолчанию
        applyTheme(false);
    }
}
```

## 🐛 Troubleshooting

### Тема не сохраняется
Проверьте что localStorage доступен:
```javascript
console.log(localStorage.getItem('pageglow-theme'));
```

### Мерцание при загрузке
Убедитесь что inline скрипт в `<head>` загружается до контента.

### Темы нет на некоторых страницах
Проверьте что все страницы наследуются от `base.html`.
