# 📱 Социальные функции в PageGlow

## ✅ Что реализовано

Полноценная система социальных функций:

- ✅ **Закладки** - сохранение статей
- ✅ **Коллекции** - группировка закладок по папкам
- ✅ **Достижения** - система бейджей
- ✅ **Рекомендации** - персональная лента

## 🎯 URL

```
Закладки:         /bookmarks/
Добавить закладку: /bookmarks/toggle/
Коллекции:        /collections/{id}/
Создать коллекцию: /collections/create/
```

## 📁 Модели

### Bookmark (Закладка)

| Поле | Тип | Описание |
|------|-----|----------|
| user | FK | Пользователь |
| post | FK | Статья |
| collection | FK | Коллекция (опционально) |
| created_at | DateTime | Дата создания |
| notes | Text | Заметка (до 500 символов) |

### Collection (Коллекция)

| Поле | Тип | Описание |
|------|-----|----------|
| user | FK | Пользователь |
| name | Char | Название |
| description | Text | Описание |
| is_public | Boolean | Публичная или нет |
| created_at | DateTime | Дата создания |
| updated_at | DateTime | Дата обновления |

### UserBadge (Достижение)

| Поле | Тип | Описание |
|------|-----|----------|
| key | Char | Уникальный ключ |
| name | Char | Название |
| description | Text | Описание |
| icon | Char | Иконка (emoji) |
| color | Char | Цвет бейджа |
| is_active | Boolean | Активно |
| order | Integer | Порядок отображения |

### UserAchievement (Полученное достижение)

| Поле | Тип | Описание |
|------|-----|----------|
| user | FK | Пользователь |
| badge | FK | Бейдж |
| earned_at | DateTime | Дата получения |
| reason | Text | Причина получения |

## 🎨 Функционал

### Закладки

**Добавление/удаление:**
- Кнопка "📑 В закладки" на странице статьи
- AJAX запрос без перезагрузки
- Toast уведомление об успехе

**Просмотр:**
- Страница `/bookmarks/`
- Список всех сохранённых статей
- Сортировка по дате
- Пагинация (15 на страницу)

**Заметки:**
- К каждой закладке можно добавить заметку
- До 500 символов
- Отображается в списке

### Коллекции

**Создание:**
- Модальное окно в закладках
- Название, описание, публичность
- Группировка закладок

**Просмотр:**
- Список коллекций в закладках
- Детальная страница коллекции
- Счётчик статей

**Приватность:**
- Приватные видны только владельцу
- Публичные доступны всем

### Достижения

**Система бейджей:**

| Бейдж | Условие | Иконка |
|-------|---------|--------|
| Коллекционер | 10 закладок | 📚 |

**Автоматическое получение:**
- Проверяется при добавлении закладки
- Уведомление при получении
- Отображение в профиле

### Рекомендации

**Алгоритм:**

1. **Анализ закладок**
   - Любимые категории
   - Популярные теги

2. **Расчёт score**
   - Совпадение категорий × 2
   - Совпадение тегов
   - Популярность статьи

3. **Формирование ленты**
   - Исключить уже сохранённые
   - Сортировка по score
   - Дополнение популярным

**Использование:**
```python
from main.views import get_user_recommendations

recommendations = get_user_recommendations(request, limit=10)
```

## 🔧 API

### Закладки

**POST /bookmarks/toggle/**

Request:
```json
{
  "post_id": 123
}
```

Response:
```json
{
  "success": true,
  "is_bookmarked": true,
  "bookmarks_count": 15
}
```

### Закладки (список)

**GET /bookmarks/**

Response:
- Список закладок
- Пагинация
- Коллекции пользователя

## 🎯 Примеры использования

### Добавить в закладки

```javascript
fetch('/bookmarks/toggle/', {
    method: 'POST',
    headers: {
        'Content-Type': 'application/x-www-form-urlencoded',
        'X-CSRFToken': csrf_token
    },
    body: `post_id=${postId}`
})
.then(r => r.json())
.then(data => {
    if (data.success) {
        // Обновить UI
    }
});
```

### Получить рекомендации

```python
# В view
def recommended_posts(request):
    recommendations = get_user_recommendations(request, limit=10)
    return render(request, 'recommended.html', {
        'posts': recommendations
    })
```

### Создать коллекцию

```python
from main.models import Collection

collection = Collection.objects.create(
    user=request.user,
    name='Избранное',
    description='Лучшие статьи',
    is_public=False
)
```
