# 🛒 Marketplace в PageGlow

## ✅ Что реализовано

Полноценная биржа фриланс-услуг:

- ✅ **Проекты** - публикация и поиск проектов
- ✅ **Профили фрилансеров** - портфолио и навыки
- ✅ **Система отзывов** - рейтинги и комментарии
- ✅ **Заявки (bids)** - подача предложений на проекты
- ✅ **Чат** - общение между заказчиком и исполнителем
- ✅ **AI-матчинг** - автоматический подбор фрилансеров

## 🎯 URL

### Основные страницы

```
Marketplace:     https://www.pageglow.com/marketplace/
Проекты:         https://www.pageglow.com/marketplace/projects/
Фрилансеры:      https://www.pageglow.com/marketplace/freelancers/
```

### Для заказчиков

```
Создать проект:  /marketplace/projects/create/
Дашборд:         /marketplace/client/dashboard/
```

### Для фрилансеров

```
Профиль:         /marketplace/freelancers/{username}/
Редактировать:   /marketplace/freelancers/{username}/edit/
Дашборд:         /marketplace/freelancer/dashboard/
Создать профиль: /marketplace/profile/freelancer/create/
```

## 📁 Модели

### Project (Проект)
- Название и описание
- Бюджет (min/max)
- Требуемые навыки
- Срок выполнения
- Статус (опубликован, в работе, завершен)

### FreelancerProfile (Профиль фрилансера)
- Роль (Backend, Frontend, etc.)
- Навыки
- Опыт работы
- Рейтинг
- Портфолио

### Bid (Заявка)
- Предлагаемая цена
- Срок выполнения
- Сопроводительное письмо
- AI-оценка совместимости

### Review (Отзыв)
- Оценка (1-5)
- Комментарий
- Детальные оценки (качество, коммуникация, etc.)

### ProjectChat (Чат)
- Сообщения
- Файлы
- Встраивание (Figma, Miro)

## 🎨 Функционал

### Для заказчиков:

1. **Публикация проекта**
   - Описание требований
   - Установка бюджета
   - Выбор необходимых навыков
   - Срок выполнения

2. **Просмотр заявок**
   - AI-ранжирование предложений
   - Сравнение фрилансеров
   - Выбор исполнителя

3. **Чат с исполнителем**
   - Текстовые сообщения
   - Обмен файлами
   - Встроенные превью

### Для фрилансеров:

1. **Поиск проектов**
   - Фильтрация по категориям
   - Поиск по навыкам
   - Сортировка по бюджету

2. **Подача заявок**
   - Предложение цены
   - Оценка сроков
   - Сопроводительное письмо

3. **Управление профилем**
   - Навыки и специализация
   - Портфолио работ
   - Отзывы и рейтинг

## 🤖 AI Matching

Система автоматически оценивает совместимость фрилансера с проектом:

### Факторы:
- **Навыки** (40 баллов) - совпадение с требованиями
- **Опыт** (20 баллов) - соответствие сложности проекта
- **Рейтинг** (20 баллов) - средняя оценка
- **Доступность** (10 баллов) - готовность к работе
- **Верификация** (10 баллов) - проверенный профиль

### Максимальный score: 100

## 🚀 Использование

### 1. Для заказчика:

```
1. Зарегистрироваться
2. Создать проект (Marketplace → Создать проект)
3. Указать требования и бюджет
4. Просматривать заявки
5. Выбрать исполнителя
6. Начать работу в чате
```

### 2. Для фрилансера:

```
1. Зарегистрироваться
2. Создать профиль фрилансера
3. Найти подходящий проект
4. Подать заявку
5. Дождаться ответа
6. Начать работу
```
