## ✨ On-Page SEO

### Meta-теги

#### Title (Заголовок страницы)

**Требования:**
- Длина: 50-60 символов
- Уникальный для каждой страницы
- Ключевые слова в начале
- Бренд в конце

**Примеры:**
```
✅ Хорошо: "Как изучить Python в 2026: Полное руководство | PageGlow"
❌ Плохо: "Статья"
```

**Формула:**
```
[Основной ключ] + [Дополнительный ключ/УТП] + [Бренд]
```

#### Description (Описание)

**Требования:**
- Длина: 150-160 символов
- Содержит призыв к действию
- Включает ключевые слова
- Уникальное для каждой страницы

**Пример:**
```
✅ "Изучите Python с нуля до профессионала. Пошаговое руководство с 
примерами кода, упражнениями и проектами. Начните карьеру в IT уже сегодня!"
```

#### Keywords

**Автоматически генерируются из:**
- Тегов публикации
- Категории
- Содержимого статьи

### Заголовки H1-H6

**Структура:**
```
H1: Главный заголовок статьи (1 на странице)
  H2: Основные разделы
    H3: Подразделы
      H4: Детали
```

**Правила:**
- H1 содержит основной ключ
- H2-H6 отражают структуру контента
- Иерархия не нарушается

**Пример:**
```html
<h1>Как изучить Python в 2026: Полное руководство</h1>
  <h2>1. Основы Python</h2>
    <h3>Синтаксис и переменные</h3>
    <h3>Типы данных</h3>
  <h2>2. Продвинутые темы</h2>
    <h3>Объектно-ориентированное программирование</h3>
```

### URL структуры

**Оптимальные URL:**
```
✅ pageglow.ru/articles/kak-izuchit-python-2026
✅ pageglow.ru/categories/programmirovanie
✅ pageglow.ru/tags/python

❌ pageglow.ru/articles/123
❌ pageglow.ru/articles/kak_izuchit_python_2026_s_nulya_polnoe_rukovodstvo
```

**Правила:**
- Транслитерация для русского языка
- Короткие и понятные URL
- Ключевые слова в URL
- Дефисы вместо подчёркиваний

## 🔧 Техническое SEO

### Robots.txt

Файл `robots.txt` уже настроен и доступен по адресу `/robots.txt`.

**Основные правила:**
- ✅ Разрешена индексация основного контента
- ❌ Запрещены служебные страницы (admin, api, auth)
- ❌ Запрещена индексация параметров поиска и пагинации

### Sitemap.xml

Карта сайта автоматически генерируется по адресу `/sitemap.xml`.

**Включает:**
- 📄 Статьи (PostSitemap)
- 📁 Категории (CategorySitemap)
- 🏷️ Теги (TagSitemap)
- 👤 Профили пользователей (UserSitemap)
- 💬 Обсуждения (DiscussionsSitemap)

**Приоритеты:**
- Популярные статьи (>1000 просмотров): 1.0
- Статьи со средними просмотрами: 0.8-0.9
- Категории: 0.8
- Теги: 0.7
- Профили: 0.6

### Canonical URL

Для каждой страницы автоматически устанавливается canonical URL:
```html
<link rel="canonical" href="https://pageglow.ru/current-page-url" />
```

### Скорость загрузки

**Оптимизации:**
- ✅ Lazy loading для изображений
- ✅ Минификация CSS/JS
- ✅ Кэширование через Redis
- ✅ CDN для статических файлов
- ✅ Preconnect для внешних ресурсов

**Рекомендации:**
- Сжимайте изображения перед загрузкой
- Используйте WebP формат
- Оптимизируйте размер библиотек

## 📝 Контентная оптимизация

### Требования к статьям

**Минимальные:**
- ✅ Уникальность: 90%+
- ✅ Объём: от 1000 слов
- ✅ Структура: H1-H3 заголовки
- ✅ Изображения: 1-3 на статью
- ✅ Ключевые слова: 2-3% плотность

**Оптимальные:**
- Объём: 2000-3000 слов
- Изображения: 5-10
- Код: примеры с подсветкой
- Видео: опционально
- Источники: ссылки на документацию

### Чеклист публикации

Перед публикацией проверьте:

- [ ] Заголовок H1 содержит ключевое слово
- [ ] Meta Title: 50-60 символов
- [ ] Meta Description: 150-160 символов
- [ ] URL короткий и понятный
- [ ] Есть введение (100-150 слов)
- [ ] Структура H2-H3
- [ ] Ключевые слова распределены равномерно
- [ ] Изображения с alt-текстом
- [ ] Внутренние ссылки на related content
- [ ] Призыв к действию в конце
- [ ] Теги (3-5 штук)
- [ ] Категория выбрана правильно

### Оптимизация изображений

**Alt-тексты:**
```
✅ "Пример кода Python функции hello world"
❌ "image123.png"
❌ ""
```

**Названия файлов:**
```
✅ "python-hello-world-function.png"
❌ "IMG_20240315_123456.png"
```

**Форматы:**
- Фото: WebP, JPEG (качество 80%)
- Скриншоты кода: PNG
- Иконки: SVG

## 🔍 Микроразметка Schema.org

### Article (Статьи)

Автоматически добавляется для всех публикаций:

```json
{
  "@context": "https://schema.org",
  "@type": "Article",
  "headline": "Заголовок статьи",
  "image": "URL изображения",
  "datePublished": "2026-03-24T10:00:00+00:00",
  "dateModified": "2026-03-24T12:00:00+00:00",
  "author": {
    "@type": "Person",
    "name": "Имя автора"
  },
  "publisher": {
    "@type": "Organization",
    "name": "PageGlow"
  },
  "description": "Описание статьи",
  "mainEntityOfPage": {
    "@type": "WebPage",
    "@id": "URL статьи"
  }
}
```

### WebSite (Сайт)

Добавлено в base.html:

```json
{
  "@context": "https://schema.org",
  "@type": "WebSite",
  "name": "PageGlow",
  "alternateName": "ФлакХаб",
  "url": "https://pageglow.ru",
  "potentialAction": {
    "@type": "SearchAction",
    "target": "https://pageglow.ru/search/?q={search_term_string}",
    "query-input": "required name=search_term_string"
  }
}
```

### ItemList (Лента публикаций)

Для главной страницы:

```json
{
  "@context": "https://schema.org",
  "@type": "ItemList",
  "name": "Лента публикаций PageGlow",
  "itemListElement": [
    {
      "@type": "ListItem",
      "position": 1,
      "url": "https://pageglow.ru/article-1",
      "name": "Заголовок статьи 1"
    }
  ]
}
```

## 📊 Мониторинг и аналитика

### Google Search Console

**Подключение:**
1. Добавьте сайт в [GSC](https://search.google.com/search-console)
2. Подтвердите права через DNS или HTML-файл
3. Отправьте sitemap.xml

**Отслеживайте:**
- Показатели кликов (CTR)
- Позиции по ключевым словам
- Индексацию страниц
- Ошибки сканирования

### Яндекс.Вебмастер

**Подключение:**
1. Добавьте сайт в [Вебмастер](https://webmaster.yandex.ru)
2. Подтвердите права
3. Отправьте sitemap.xml

**Особенности для Яндекса:**
- Указан Host в robots.txt
- Региональность: Россия
- Категория: IT/Программирование

### Метрики

**Google Analytics 4:**
- Установите счётчик GA4
- Настройте цели (регистрация, публикация)
- Отслеживайте поведение пользователей

**Ключевые метрики:**
- Органический трафик
- Время на странице
- Глубина просмотра
- Показатель отказов

### Инструменты

**Для анализа:**
- 🔍 [Google PageSpeed Insights](https://pagespeed.web.dev/)
- 🔍 [Google Rich Results Test](https://search.google.com/test/rich-results)
- 🔍 [Schema Markup Validator](https://validator.schema.org/)
- 🔍 [Screaming Frog SEO Spider](https://www.screamingfrog.co.uk/seo-spider/)

## 🎯 Рекомендации для авторов

### Написание заголовков

**Формулы вирусных заголовков:**
1. "Как [сделать что-то] за [время]/с [результат]"
   - "Как изучить Django за 7 дней с портфолио проектов"

2. "[Число] способов/ошибок/инструментов [сделать что-то]"
   - "10 ошибок начинающего Python-разработчика"

3. "Полное руководство по [тема]"
   - "Полное руководство по Docker для начинающих"

4. "[Тема] в 2026: Что нужно знать"
   - "Веб-разработка в 2026: Что нужно знать"

### Структура статьи

```
1. Введение (100-150 слов)
   - Проблема/вопрос
   - Что будет в статье
   - Для кого статья

2. Основная часть
   - Теоретический блок
   - Практические примеры
   - Код с комментариями

3. Заключение
   - Основные выводы
   - Призыв к действию
   - Ссылки на related content
```

### Внутренняя перелинковка

**Правила:**
- 3-5 внутренних ссылок на статью
- Ссылки на категории и теги
- Ссылки на похожие статьи
- Ссылки на профиль автора

**Пример:**
```
Смотрите также:
- "Основы Python" (предыдущая статья)
- "Продвинутый Django" (следующая статья)
- Категория: "Веб-разработка"
- Тег: "Python"
```
