# 📊 Analytics Dashboard в PageGlow

## ✅ Что реализовано

Полноценная панель администратора с аналитикой:

- ✅ **Общая статистика** - карточки с ключевыми метриками
- ✅ **Графики активности** - Chart.js визуализация
- ✅ **Популярные статьи** - топ 10 по просмотрам
- ✅ **Активные авторы** - топ 10 по публикациям
- ✅ **Последние комментарии** - лента комментариев
- ✅ **API статистики** - JSON endpoint
- ✅ **Защита доступом** - только для staff

## 🎯 URL

```
https://www.pageglow.com/dashboard/
```

**Доступ:** Только для пользователей с `is_staff=True`

## 📊 Статистика

### Общие метрики:

| Метрика | Описание |
|---------|----------|
| Всего статей | Общее количество постов |
| Опубликовано | Опубликованные посты |
| Пользователей | Активные пользователи |
| Комментариев | Все комментарии |
| Обсуждений | Опубликованные обсуждения |

### Периоды:

- **За неделю** - новые пользователи, посты, комментарии
- **За месяц** - динамика публикаций
- **За 30 дней** - график активности

### Топы:

- 🔥 **Популярные статьи** - по просмотрам и лайкам
- ⭐ **Активные авторы** - по количеству статей
- 💬 **Последние комментарии** - свежие комментарии

## 📈 Графики

### Активность за 30 дней

Линейный график с двумя наборами данных:
- **Просмотры** (синий) - сумма просмотров статей по дням
- **Статьи** (зелёный) - количество новых статей по дням

### По категориям

Круговая диаграмма (doughnut):
- Распределение статей по категориям
- Цветовое кодирование для каждой категории

## 🔌 API Статистики

### Endpoint

```
GET /api/analytics/
```

**Требования:**
- Авторизация обязательна
- Пользователь должен быть `is_staff=True`

### Параметры

| Параметр | Значение по умолчанию | Описание |
|----------|----------------------|----------|
| `period` | 30 | Период в днях |

### Пример запроса

```bash
curl -X GET "http://localhost:8000/api/analytics/?period=7" \
  -H "Authorization: Bearer <token>"
```

### Пример ответа

```json
{
  "total_posts": 150,
  "published_posts": 142,
  "total_users": 89,
  "total_comments": 523,
  "total_discussions": 45,
  "period_stats": {
    "new_posts": 12,
    "new_users": 5,
    "new_comments": 34
  }
}
```

## 🔐 Безопасность

### Проверка доступа

```python
def dispatch(self, request, *args, **kwargs):
    if not request.user.is_staff:
        messages.error(request, 'Доступ запрещён')
        return redirect('home')
    return super().dispatch(request, *args, **kwargs)
```

### API защита

```python
if not request.user.is_staff:
    return JsonResponse({'error': 'Доступ запрещён'}, status=403)
```

## 🎯 Использование

### Для администраторов:

1. Войдите в систему под учётной записью staff
2. Нажмите на аватар в шапке
3. Выберите "Панель админа"
4. Изучайте статистику и графики

### Для разработчиков:

```python
# Получение статистики через API
import requests

response = requests.get(
    'http://localhost:8000/api/analytics/',
    params={'period': 7},
    headers={'Authorization': f'Bearer {token}'}
)
stats = response.json()
```
