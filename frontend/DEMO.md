# Демо-стенд ФлакХаба

Публичная статическая версия фронтенда для показа без Django-сервера:
**https://flachub.ru/** (канонический адрес). Временная копия до переезда
доступна на GitHub Pages: `https://guseintarss.github.io/`.

Демо собирается из `frontend/` с флагом `VITE_DEMO=true`. В обычной сборке
флаг не выставлен, поэтому демо-код не попадает в бандл и приложение работает
с настоящим API как раньше.

## Учётные записи

| Роль | Логин | Пароль |
|------|-------|--------|
| Пользователь | `demo` | `demo1234` |
| Администратор | `admin` | `admin1234` |

На странице входа в демо-режиме есть кнопки быстрого входа. Остальные
тестовые пользователи используют пароль `demo1234`.

## Как это работает

- `frontend/src/demo/installDemo.js` подменяет `window.fetch` только для
  `/api/mobile/*`, `/upload/` и `/ajax/subscribe/`, а также эмулирует
  WebSocket для уведомлений, чатов и комментариев к статье.
- Ответы повторяют контракты Django mobile API: поля, пагинацию,
  коды ошибок и проверки прав. Дашборд автора и импорт с Хабра тоже
  работают в демо-режиме.
- Всё состояние лежит в `localStorage` под ключом `flachub-demo-state`.
  Изменения видны только в текущем браузере и сохраняются после перезагрузки.
- Загруженные изображения сжимаются в WebP на клиенте и хранятся как data URL.
- Кнопка «Тур 90 секунд» в демо-бейдже запускает сценарий: разбор кода →
  замечание к строке → ответ ревьюера по WebSocket → дашборд автора.
- Кнопка «Сбросить» в левом нижнем углу удаляет состояние и возвращает
  исходные демо-данные.
- Письма сброса пароля не отправляются: стенд предлагает использовать
  пароль из таблицы выше.
- Django Admin в демо скрыт, потому что серверной части на стенде нет.

## Сборка и публикация

```bash
./tools/deploy-demo-pages.sh
```

Скрипт собирает `frontend/build` с `VITE_DEMO=true`, добавляет `.nojekyll`,
копирует `index.html` в `404.html` для SPA-маршрутов и публикует содержимое
в репозиторий `guseintarss.github.io` (GitHub Pages, ветка `main`).

Требования: `npm`, авторизованный `gh` с доступом к репозиторию. Другой
репозиторий можно указать через `DEMO_PAGES_REPO=owner/repo`.

## Локальная проверка

```bash
cd frontend
VITE_DEMO=true npm run build
npm run preview -- --port 4173
```

Откройте `http://localhost:4173/`. Для проверки production-поведения без демо
используйте обычный `npm run build` и запуск через Django/nginx.
